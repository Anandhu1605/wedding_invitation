## Free Deployment via GitHub Pages

To share this digital invitation with family and relatives:

1. Push this repository to GitHub.
2. In your GitHub repository, navigate to **Settings** > **Pages** (under "Code and automation").
3. Under **Build and deployment** > **Branch**:
   - Select **`main`** branch and folder **`/ (root)`**.
   - Click **Save**.
4. GitHub will give you a public link (e.g., `https://<username>.github.io/<repo-name>/`).
5. Share the link on WhatsApp — it will automatically show a rich card preview with the auspicious `॥ शुभमस्तु ॥` blessing, couples' names, and wedding dates.

## Adding Custom Background Music

Place any MP3 audio file named **`wedding-music.mp3`** in the root directory. The music player toggle will automatically play it when clicked. (If absent, a gentle Indian classical ambient drone chord is synthesized via the Web Audio API).
